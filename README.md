# 🎮 Simon Says Game

A fun and interactive memory game built using **HTML, CSS, and JavaScript**. The player must remember and repeat the sequence of flashing colored buttons. With every correct answer, the game advances to the next level and increases the difficulty.

## 🚀 Features

* **Interactive Gameplay:** Play using four colored buttons.
* **Level System:** Progress through levels by repeating the correct sequence.
* **Random Sequences:** A random color is added at each new level.
* **Flash Animations:** Visual effects help players identify the sequence.
* **Score Tracking:** Displays the score when the game ends.
* **Start and Reset Controls:** Start a new game or reset the current game.
* **Responsive Design:** Play on desktop and mobile screens.
* **Game Over Effect:** Visual feedback when an incorrect button is pressed.

## 🛠️ Technologies Used

* **HTML5** – Structures the game interface.
* **CSS3** – Styles the buttons, layout, animations, and responsive design.
* **JavaScript** – Implements game logic, random sequences, level progression, and answer validation.

## 💻 How to Run the Project

Follow these steps to run the game on your computer.

1. **Download or clone the repository.**

2. **Open the project folder.**

3. **Run the game.**

   * Open `index.html` in your web browser.
   * Alternatively, use the Live Server extension in Visual Studio Code.

4. **Start playing!**

   * Click the **START** button.
   * Watch the colored button that flashes.
   * Click the corresponding button.
   * Repeat the sequence as it grows with each level.
   * Avoid incorrect selections to achieve a higher score.

## 🎯 How to Play

1. Click the **START** button to begin.
2. Observe the colored button that flashes.
3. Click the same button to repeat the sequence.
4. Remember the previous sequence as a new color is added.
5. Continue repeating the sequence correctly to advance through levels.
6. If you select the wrong button, the game ends and your score is displayed.
7. Click **RESET** to return to the initial game screen.
